# Exploration Checklist

Use this checklist before finalizing the discovery artifact.

## Global Surface

- Landing page and primary navigation
- Header, footer, sidebar, breadcrumbs
- Role- or auth-specific navigation differences

## Nested Navigation

- Tabs and tab panels
- Accordions and collapsible regions
- Drawers, side panels, and popovers
- Modal dialogs and nested dialogs
- Table row drill-ins and detail pages
- Card clicks and nested links
- Pagination, infinite scroll, and "load more"
- Multi-step wizards and step transitions

## Data Interactions

- Search, filters, sorts, and resets
- Empty states
- Loading states
- Validation errors
- Success confirmations
- Server or permission errors

## File and External Boundaries

- Uploads
- Downloads
- External redirects or new tabs
- Background jobs or async completion

## Automation Readiness

- Reusable actions identified
- Preconditions documented
- Stable anchors noted where obvious
- Test candidates prioritized
- Unknowns and blockers clearly separated from confirmed behavior
