# ts-playwright Codex Plugin

Project-local Codex plugin for this repository.

## Provides

- a local Playwright MCP entry point for browser automation in this repo;
- project-local wrapper skills for Playwright E2E work, browser debugging, and site discovery;
- a repo marketplace entry so the plugin can be discovered with the repository.

## Key Files

- `.codex-plugin/plugin.json`
- `.mcp.json`
- `scripts/run-playwright-mcp.cmd`
- `skills/ts-playwright-e2e/SKILL.md`
- `skills/ts-playwright-browser-debug/SKILL.md`
- `skills/ts-playwright-site-discovery/SKILL.md`
